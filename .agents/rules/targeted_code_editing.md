# Global Rules for Antigravity AI Assistant

## Strict Targeted Code Modifications
1. **Inspect Full Codebase**: Always review and re-check the full codebase before making changes.
2. **Targeted Edits Only**: Apply code edits strictly and exclusively to the exact section, component, or button specified in the user's request.
3. **No Unintended Changes**: Do NOT modify, delete, or refactor any unrelated functions, styles, or translations.
