# 📜 ОФИЦИАЛЬНЫЙ СВОД ПРАВИЛ ELEVENLABS: ЗАМЕДЛЕНИЕ И ПОНИЖЕНИЕ ТОНА ГОЛОСА

> **Спецификация техник ElevenLabs API & VoiceLab**  
> Составлена на основе официальной документации ElevenLabs и рекомендаций форума разработчиков (ElevenLabs Discord / Community Forum).

## 🥇 I. ПРАВИЛА И ТЕХНИКИ, ЗАМЕДЛЯЮЩИЕ И ПОНИЖАЮЩИЕ ГОЛОС (ТОП-ПРИОРИТЕТ)

### 1. 🛑 Интонационная пунктуация (Тире `—`, Многоточия `...` и Запятые `,`)
* **Механика ElevenLabs**: Нейросеть ElevenLabs Multilingual воспринимает пунктуацию как эмоциональные и дыхательные маркера.
* **Правило**:
  - Длинное тире (`—`) заставляет алгоритм **протягивать гласные звуки и понижать тон голоса на 1-2 полутона** перед паузой.
  - Запятая (`,`) и многоточие (`...`) делят фразу на глубокие выдохи.
* **Пример**:
  ```text
  Дорогой мой... родной человечек, Аня... — <break time="3.5s"/>
  ```

### 2. 🐢 Параметр скорости API (`speed: 0.70`)
* **Правило**: Параметр `speed` в объекте `voice_settings` API явно задает темп речи.
* **Порог API**: Минимально допустимое значение API равно **`0.70`** (70% от стандартной скорости речи).
* **Настройка**:
  ```json
  "voice_settings": {
    "speed": 0.70
  }
}
  ```

### 3. 📉 Понижение тона при клонировании образца (Pitch Shift -3 Semitones)
* **Правило**: Нейросеть ElevenLabs клонирует не только тембр, но и базовую высоту тона (Pitch) из загруженного файла.
* **Техника**: Предварительное понижение тона аудиозаписи родителя на **-2...-3 полутона** перед отправкой в Instant Voice Cloning (`/v1/voices/add`) создает глубокий, бархатный, убаюкивающий грудной голос.

### 4. ⚖️ Настройка стабильности (`stability: 0.50`)
* **Правило**: 
  - Высокая стабильность (`0.85+`) при коротких фразах может вызывать эффекты сжатия и ускорения первых слов.
  - Стабильность **`0.50 – 0.60`** удерживает ровный, плавный, расслабленный ритм дыхания без спешки на первых фразах.

## 🥈 II. ВСПОМОГАТЕЛЬНЫЕ ПРАВИЛА СИНТЕЗА И СТИЛЯ

### 5. 🧘 Устранение драматических всплесков (`style: 0.00`)
* **Правило**: Установка `style: 0.00` исключает искусственные эмоциональные прыжки высоты тона, сохраняя голос мягким, ровным и убаюкивающим.

### 6. 📄 Вынос каждой фразы на отдельную строку (`\n\n`)
* **Правило**: Разделение предложений двойным переносом строки (`\n\n`) заставляет нейросеть воспринимать каждое предложение как независимый завершенный выдох, предотвращая ускорение речи.
